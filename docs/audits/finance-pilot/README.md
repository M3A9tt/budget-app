# Пилот OCR и финансового помощника 5.1.23

## Контрольные сценарии

На вымышленном профиле карта начинается с 1 000 ₽. Перед распознаванием чеков и запуском модели профиль уже загружен обычным способом.

| Действие | Результат |
| --- | --- |
| Прочитать снимок, проверить дату, валюту и итог 123,45 ₽, перенести в форму | Записей нет, остаток 1 000 ₽ |
| Сохранить расход. Потерять первый ответ и повторить запрос с тем же ключом | Одна запись, остаток 876,55 ₽ |
| Выбрать тот же чек и отменить | Видно предупреждение о похожем расходе, записей по-прежнему одна |
| Купить сегодня за 500 ₽ по расчёту | Остаток в сценарии на день покупки 376,55 ₽, минимум за горизонт 253,10 ₽. Фактический остаток 876,55 ₽ |
| Отказаться от облачного разбора, затем запросить его и получить отказ по квоте | При отказе запроса нет. При сбое расчёт остаётся доступным |
| Удалить сохранённый расход через «Операции» | Записей нет, остаток снова 1 000 ₽ |

OCR в Chromium распознаёт синтетический PNG настоящим движком. Сценарии авторизации, повторной записи и ответа облака используют тестовый API. Суммы и варианты восстановления дополнительно проверяются доменными тестами. Миграции и записи финансового помощника в D1 отсутствуют.

## Запуск на staging

- `STAGING_RECEIPT_OCR_PILOT=on` включает сканирование в форме. `STAGING_FINANCE_ASSISTANT_PILOT=on` включает расчёт и пробу WebGPU. Каналы включаются независимо для владельца и ID из `STAGING_FINANCE_PILOT_IDS`. Участникам нужен действующий доступ к staging.
- Убедиться, что аккаунт Cloudflare находится на **Workers Free**. Только после проверки задать `STAGING_FINANCE_ASSISTANT_WORKERS_FREE=confirmed`. Конфиг добавит привязку Workers AI. При смене тарифа убрать подтверждение и повторить выкладку. Для разработки доступны обе формы на `/?demo=1`, облако в демо отключено. [Квота и тарификация Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- Перед включением для пользователей проверить в Telegram на физических Android и iPhone. Для OCR пройти чёткий и смазанный снимок, скриншот, спорный итог, валюту и дату, отмену и дубль. Старую операцию сверить в истории, аналитике и календаре. Для помощника проверить загрузку модели с нуля и из кэша, отмену, пригодность объяснений на русском, явное согласие на бесплатное облако и отказ при исчерпании квоты. На обеих платформах должен работать бесплатный вариант. Если условие для помощника не выполнено, включить только прошедший приёмку OCR.
- Локальную проверку запускают команды `npm test`, `npm run build`, `npm run worker:check` и `npm run test:pilot`. Для другого Chromium задать `BROWSER_EXECUTABLE_PATH`. Снимки и фикстура сохраняются в `PILOT_SCREENSHOT_DIR` или в `/tmp/burget-finance-pilot`.

Реальные Telegram WebView, запуск WebLLM на телефоне и настоящий вызов Workers AI остаются открытыми пунктами приёмки. Флаги staging по умолчанию выключены.
