# Бюрджет 5.1.25 — проверка сквозных сценариев

Слева версия 5.1.24 (`6c9df2b`), справа версия 5.1.25 из коммита этого отчёта. Снимки сделаны в Chromium на одном вымышленном профиле за 21 ноября 2026 года. На каждом сравнении видна первая область экрана. Полные снимки пяти экранов доступны при повторном запуске.

| Сценарий | Изменение и проверенный результат | Снимки |
| --- | --- | --- |
| Главная и счета | Бюджет занимает первый экран в стандартной раскладке. «Расчёт» раскрывает баланс, рядом доступен резерв. В пустом профиле первый счёт на 1 000 ₽ и расход на 77,01 ₽ дали остаток 922,99 ₽ и одну запись. UX-01, UX-02, UX-04 | [320 px](home-320.webp), [390 px](home-390.webp), [1280 px](home-1280.webp) |
| Запись и OCR | В проверке распознанные 123,45 ₽ и комиссия 0,02 ₽ дали списание 123,47 ₽. Дата в будущем переводит запись в план. Возврат из OCR сохраняет введённое. UX-01, UX-03 | [390 px](entry-390.webp) |
| Аналитика | Период и категория передаются в журнал. Возврат восстанавливает отчёт за 7 дней. Оценка покупки доступна при выключенной модели. UX-02, UX-03 | [390 px](analytics-390.webp) |
| Операции | Фильтры снимаются по одному или все сразу. Вход из истории обедов сохраняет предыдущий поиск в журнале. Импорт одной записи на 12,34 ₽ сохраняет её в истории с исходной суммой и не меняет остатки. UX-02, UX-03 | [390 px](operations-390.webp) |
| Календарь и бот | Ссылка напоминания открывает конкретное событие. В проверке отметка оплаты списала 800 ₽ с остатка 1 000 ₽ один раз. Повторный переход по устаревшей ссылке открыл день с пояснением. UX-02, UX-03 | [390 px](calendar-390.webp) |

`?demo=1` открывает заполненный профиль, `?demo=1&sample=empty` — первый запуск. Изменения в обоих демо хранятся до перезагрузки страницы. Архив `?classic=1` использует локальные данные того же адреса, на котором они были созданы.

Для повторной съёмки выполните `npm ci` и `BROWSER_EXECUTABLE_PATH=/usr/bin/chromium npm run test:workflows`. Нужен коммит `6c9df2b` в локальной истории. Скрипт создаёт временный Git worktree, фиксирует дату, подставляет вымышленный профиль и сохраняет снимки и фикстуру в `/tmp/burget-workflows-preview`. Путь можно изменить переменной `WORKFLOWS_SCREENSHOTS`.

Поведение кнопки «Назад» проверено в Chromium с эмуляцией Telegram WebApp. Серверные тесты охватывают формирование ссылок бота. Проверка на отдельном реальном Telegram-аккаунте остаётся открытой.
