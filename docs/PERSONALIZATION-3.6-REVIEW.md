# Бюрджет 3.6 — публикация одобрена

База: 3.5.0.0, staging a5559ce5a07f707f5378e0c5327e80e76ef432a1.

## Одна ссылка для всех

Владелец создаёт /invite: многоразовая ссылка без срока действия, пока не
отключена командой /invite_close. Ссылка хранится только хешем. Общий токен
не служит ключом к финансовому профилю: после входа проверяется личное членство.
У каждого участника отдельный пустой бюджет. Старые одноразовые приглашения
совместимы. Закрытие ссылки не отзывает уже выданное членство.

/friends показывает участников по 40 на странице, /friends 2 — следующая.
Владелец закрывает и восстанавливает доступ индивидуально. Отозванное членство
не восстанавливается повторным входом по другой общей ссылке; существующая
веб-сессия сразу теряет доступ. Финансовые данные сохраняются. Доступ из
конфигурации окружения управляется прежним способом.

Аддитивные таблицы user_join_links/user_memberships создаются лениво через D1;
старые user_invites и финансовые профили не переписываются. allAllowedUsers
объединяет действующее членство для расписания и рассылки обновлений.

## Модули и главная

Общий setModule используется переключателями миниаппы и ботом. Дополнительные
разделы скрываются из меню; записанные обязательства продолжают учитываться
и доступны из расчёта бюджета и списка наступивших платежей.

Главная: 11 блоков, пресеты «Минимум», «На каждый день», «Всё под рукой».
Блоки скрываются и переставляются стрелками, быстрая запись остаётся доступной.
Настройки homeLayout хранятся в профиле, валидируются и входят в полный бэкап.
Один порядок и видимость используются ботом и миниаппой. В боте эквиваленты
графических блоков открывают соответствующие общие разделы; картинка бюджета
не отправляется, если блок бюджета скрыт. Это настройка содержания/порядка,
не редактор тем и цветов. Сброс главной сохраняет настройки модулей.

Новые профили начинают с простой главной и выключенных дополнительных модулей.
Существующие профили сохраняют прежние defaults, явные настройки и данные.
Главная → Настроить открывает редактор с модулями; также Настройки → Модули и главная.
Бот: Настройки → Моя главная / Модули.

Проверки охватывают многократный вход по одному токену, раздельные профили,
старые ссылки, отзыв и восстановление доступа, сессию после отзыва, участие
в общей рассылке, настройки через webhook и подтверждение, изоляцию пользователей,
бэкап, валидацию, общий бюджет при скрытых модулях, SSR порядка и видимости.

Сравнение HTML — реальные React-компоненты на демонстрационных данных,
не скриншоты браузера или Telegram. Визуальный browser E2E не выполнялся.
