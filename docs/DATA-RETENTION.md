# Хранение данных и диагностика

Политика для 4.7.0, 29 октября 2026 года.

| Данные | Текущий срок / правило | Причина |
| --- | --- | --- |
| Основной профиль | До явного изменения пользователем; автоматического обрезания операций нет | Финансовая история должна сохраняться |
| Снимки перед записью | 50 последних ревизий, атомарно с записью | Защита от ошибочного действия; не независимая аварийная копия |
| Квитанции финансовых команд | Без автоматического удаления | Старый ключ повтора не должен снова списать деньги |
| Квитанции отчётов | 90 дней | Генератор создаёт актуальные сообщения, а не старые отчёты за произвольную дату |
| Ответы фоновых проверок | 30 дней | Ответы об обедах также хранятся в профиле; старые вопросы не воспроизводятся пачкой |
| Доставленная обратная связь | 90 дней | Недоставленные сообщения сохраняются для разбора |
| Черновик обычного ввода | До 24 часов на устройстве, отдельно для каждого пользователя | Продолжение после перезагрузки; удаляется после сохранения или выхода |
| Вход в браузере | До 7 дней; код входа — 5 минут | Сеансы можно отозвать из настроек |
| Рендеры картинок | Кэш и дневные квоты; счётчики квот — 7 дней | Общая стоимость ограничена, по умолчанию до 6 новых рендеров на пользователя и 24 на сервис в сутки |
| Неопределённая доставка | Сохраняется в outbox для расследования, без слепого автоматического повтора | Внешняя отправка и квитанция БД не являются одной транзакцией |

Полный JSON-экспорт содержит читаемые финансовые данные. Пользователь может сохранить его независимо от базы сервиса. Пятьдесят ревизий внутри той же базы не защищают от потери самой базы.

Сервер обрабатывает данные для бота и отчётов. Сквозное шифрование, скрывающее профиль от сервера, не заявляется. Необязательный зашифрованный экспорт и автоматизированные независимые копии — отдельные изменения с проверкой восстановления.

Журналы качества записи содержат маршрут, длительность, состояние и случайный код обращения. Суммы, названия счетов, тексты покупок, содержимое профиля и сессионные секреты в такую диагностику не включаются. Метрики и ошибки журналирования не должны менять результат финансовой команды.

Фоновые проверки обходят профили страницами по 25 с сохранённым курсором. Пропуск часа не теряет актуальную сводку за текущий день. Общая сводка и задания дополнительно проверяются перед отправкой по текущему профилю.

Удаление операции из активного учёта не означает немедленное исчезновение её из журнала и предыдущих снимков. Управление полным удалением профиля и окончательным удалением его копий требует отдельного документированного сценария; 4.7.0 его не выдаёт за готовую функцию.
