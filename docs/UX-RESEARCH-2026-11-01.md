# 4.10.0: интерфейс с опорой на пользовательские задачи

Основа: 7a662b52a1ba7db08440b3fcb3685c492ce9e278. Запрос: меньше декоративного «ИИ-дизайна», больше понятного повседневного интерфейса.

## Что изучено

- [YNAB: новая структура приложения](https://www.ynab.com/whats-new/the-great-ynab-remodel): главная собирает важные состояния и быстрый ввод, история выделена в отдельное место. Для Бургета взят принцип приоритета задач; продукт и метод конвертов целиком не копируются.
- [Actual Budget: счета](https://actualbudget.org/docs/accounts/): явное представление счетов и их влияния на бюджет. Для Бургета — строки счетов с выровненными суммами вместо набора цветных плиток.
- [NN/g: progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/): частые действия доступны сразу, редкие подробности раскрываются по запросу. Для Бургета — расчёт и его пояснение разделены: ключевые суммы остаются, длинный текст спрятан за «Как посчитано».

Это источники решений, а не доказательство удобства конкретного интерфейса Бургета. Пользовательское исследование на группе людей не проводилось.

## Реальные изменения

1. «Платежи» открываются с главной одним нажатием; старые маршруты сохранены. Это сокращение пути, а не только перекраска.
2. На главной одна основная финансовая поверхность. Нет нижнего рекламного блока «Разобраться в расходах», дублировавшего аналитику в навигации. Длинное объяснение расчёта раскрывается отдельно; предупреждения о нехватке и неизвестных суммах остаются видимыми.
3. Счета — обычные строки: название слева, сумма справа. Резерв — компактная строка. Убраны декоративные градиенты, лишние обводки, большие радиусы и тени в затронутых блоках. Цвет используется для финансового состояния и выбранного действия.
4. «Уже учтено» открывает выбор существующей записи с поиском по сумме, дате и назначению. Лимит первых 100 результатов поясняется; поиск позволяет добраться до старых записей без повторного списания.
5. Сохранены пользовательская настройка блоков главной, имена привычных разделов, тёмная тема, подтверждение финансовых действий и явный выбор исходной записи. Расчёты и миграция данных этим изменением не затрагиваются.
