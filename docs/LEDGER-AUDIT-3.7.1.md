# Аудит общей записи и отмены: 3.7.1

## Подтверждённые ошибки

1. Перенос покупки 10 USD со старой оценкой 920 ₽ на другой счёт после изменения курса на 120 ₽ переписывал оценку в 1200 ₽. Историческая оценка теперь зависит от суммы и валюты операции, а не выбора счёта.
2. Списание в валюте самого счёта вычислялось через округлённую рублёвую оценку. При малом допустимом курсе это могло превратить 0,01 единицы в нулевое списание. Для совпадающих валют используется исходная сумма. Зафиксированные прежние списания при правке комментария сохраняются.
3. Уже использованная отмена удаления могла сработать ещё раз после последующих редактирования и удаления той же операции. Теперь событие должно оставаться в текущем журнале.
4. Отмена доверяла полям сохранённой клиентом копии события. Теперь из аргумента берётся только ID; данные операции читаются из общего журнала.
5. При одновременном повторе одного сохранения проигравший запрос показывал конфликт, хотя результат уже был успешно записан. Общий `readReceipt` используется перед записью и после проигранного сравнения ревизий в боте, API операций и сохранении полного состояния. Чужие данные под занятым ключом не принимаются; настоящие конфликты ревизий сохраняются.

Каждая ошибка воспроизведена падающей регрессионной проверкой перед исправлением.

## Проверка и границы

287 тестов, Vite build и worker:check. Восемь новых проверок: четыре сценария журнала, три детерминированных порядка конкурирующих запросов и сквозное изменение счёта валютной операции через бот с отменой и проверкой истории/остатков.

Нет миграции схемы, массового пересчёта записей или изменения существующих пользовательских остатков. Изменения работают при последующих действиях. Текущие записи с известными `accountAmount` при неизменных сумме/валюте/счёте сохраняют исходное фактическое списание.

Аудит этого выпуска ограничен финансовой подготовкой, отменой и повторными запросами. Сохранённый совместимый путь старых вопросов об обедах (`habitAmount → save`) остаётся отдельным кандидатом на последующее объединение, как описано в BOT-CHECKS-3.7-REVIEW.md.
