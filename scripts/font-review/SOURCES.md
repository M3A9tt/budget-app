# Local typography review

Fonts are unmodified downloads from the Google Fonts repository. Each original OFL license is included. This directory is outside production public assets. The image is the user-reviewed generated logo concept and is used via CSS framing for font comparison only.

- Unbounded: https://github.com/google/fonts/tree/main/ofl/unbounded
- Commissioner: https://github.com/google/fonts/tree/main/ofl/commissioner
- Montserrat Alternates: https://github.com/google/fonts/tree/main/ofl/montserratalternates
- Literata: https://github.com/google/fonts/tree/main/ofl/literata

Source TTF filenames are recorded in scripts/capture-font-review.mjs. Commissioner uses FLAR 100 and VOLM 50. Literata uses opsz 32. All specimens use weight 600; large text is 36px, header text 18px.
