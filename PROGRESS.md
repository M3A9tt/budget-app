# Budget: результат модернизации от 13 октября 2026

Подготовлена версия 2.1.0-staging.1. Production https://budget.apersunov5.workers.dev/ не изменён. Платных AI API нет. Доступа к Cloudflare-аккаунту и тестовому Telegram-боту в этой сессии нет, поэтому живое подключение не выполнено.

## Выполнено

- Аудит исходного приложения сохранён в AUDIT.md. Финансовое ядро общее для интерфейса и бота; исправлены валютные списания/возвраты и пересчёт при редактировании заметки, двойные комиссии, отмена и конфликты ревизий.
- Тёмный интерфейс с быстрым вводом, историей и поиском по дате/СБП, графиками, разделами счетов, целей, платежей и настроек. Формы второстепенных действий свёрнуты.
- СБП как способ оплаты. Переводы своих денег не считаются расходом. Сверка сохраняет отдельную корректировку и не создаёт фиктивный доход.
- Накопления привязаны к реальному счёту. Рассрочки имеют график с точными копейками; после подтверждения возникает расход. Удаление расхода снова открывает платёж.
- Создание постоянных платежей и пауза, категории и лимиты, журнал долгов/возвратов, учёт корпоративных обедов/отгулов/частичных дней.
- CSV-предпросмотр, проверка ошибок и дублей; история без изменения остатков или новые операции со списанием. JSON перенос/экспорт и атомарные серверные копии перед полной заменой.
- Веб-вход через одноразовый код от Telegram-бота, ограниченный срок, защищённая cookie, выход. Данные общие с Mini App.
- Настройки напоминаний и ежедневных/еженедельных/ежемесячных отчётов по Москве. Сравнение с предыдущим периодом, накопления и свободные деньги в сводке. Серверный код расписания готов, но доставка не включена без deployment и бота.
- Прогноз на 30 дней с явными допущениями. API для будущего взаимодействия с ассистентом; подключение ChatGPT к нему пока отсутствует.

## Что ещё до полноценного запуска

1. Развернуть staging в существующем Cloudflare-аккаунте с отдельной D1 и тестовым ботом. Инструкция в README. Production Worker и его данные не затрагивать.
2. Импортировать миграционную копию, сверить остатки с банковскими приложениями и проверить сценарии на телефоне.
3. Довести полный паритет нового интерфейса: расширенный календарь, редактирование старых целей и часть вспомогательных инструментов пока остаются в сохранённом классическом интерфейсе. Классический интерфейс использует отдельное локальное хранилище, не общую D1.
4. Проверить устойчивость доставки уведомлений при сбоях; текущая защита от обычного повторного запуска не обеспечивает exactly-once при падении во время отправки.
5. Подключить защищённый API к ассистенту, если нужен прямой ввод из этого чата. Сам факт наличия API не даёт ChatGPT доступ автоматически.
6. После приёмки сделать свежий экспорт production, перенести новые записи, выполнить проверку и только затем переключить действующий Worker; сохранить возможность отката.

Нет автоматического доступа к банку, OCR, офлайн-очереди и платного AI. Скриншоты можно разбирать здесь и импортировать проверенный CSV. Журнал долгов, как прежде, не изменяет остатки банковских счетов. Все ограничения зафиксированы в README.
